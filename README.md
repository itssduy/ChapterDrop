# # ChapterDrop
#### Description: A Discord bot to track manga from MangaDex, send latest chapter notifications, and display manga info with cover images.

## Features

/search [manga] — search for a manga and see its description and cover.

/track [manga] — track a manga and get notified when a new chapter is uploaded.

Automatic updates via background loop every 10 minutes.

Supports multiple users and personalized tracking.
